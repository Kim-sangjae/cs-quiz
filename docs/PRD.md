# PRD: CSORA (CS Quiz)

## 목표
CS 기초 지식을 객관식 문제 풀이로 반복 학습할 수 있는 웹 서비스.

## 사용자
CS 지식을 점검하거나 학습하고 싶은 개발자 지망생 및 현직 개발자.

---

## 핵심 기능

### 1. 시작 화면 (`/`)
- 서비스 소개 문구 + 시작 버튼 → `/quiz`로 이동
- 전체 문제 수 표시 (카테고리 수 하드코딩 금지 — 카테고리는 추가/삭제 가능)
- 카테고리별 TOP 5 랭킹 섹션 (60초 revalidation)

### 2. 퀴즈 진행 화면 (`/quiz/play`)

#### 초기화
- 전체 문제 풀에서 20개를 랜덤 샘플링하여 퀴즈 세션 구성
- 최근 3세션에 출제된 문제는 샘플링에서 제외 (다양성 확보)
- 세션은 컴포넌트 마운트 시 1회만 초기화

#### 문제 표시
- 문제는 1번부터 20번까지 순차 표시
- 각 문제: 카테고리 배지 + 질문 텍스트 + 4지선다 보기 (A/B/C/D 레이블)
- 현재 문제 번호 및 진행률 표시 (예: `7 / 20`)
- 진행률 바 (선택 완료된 문제 수 / 20 기준)
- **보기 순서**: `questions.ts`에 정의된 순서 그대로 표시. 보기 셔플 없음.
- **출제 순서**: 20문제는 카테고리 정렬 없이 샘플링된 랜덤 순서 그대로 출제

#### 답안 선택
- 보기 클릭 시 해당 보기가 선택 상태로 강조
- 이미 선택한 보기를 다시 클릭해도 선택 해제되지 않음 (다른 보기 클릭해야 변경)
- **자동 이동 토글**: 상단 "자동이동" 버튼으로 보기 선택 후 500ms 뒤 다음 문제 자동 이동을 켜고 끌 수 있다 (기본값 켜짐). 설정은 localStorage(`quiz-auto-advance`)에 유지
- **키보드 단축키**: `←`/`→` 이전·다음 문제, `1~4` 보기 선택. 모달이 열려있을 때 비활성화

#### 네비게이션
- 이전 / 다음 버튼으로 문제 이동
- 문제 번호 점프 네비게이터: 1~20 번호 버튼 표시
  - 미선택: 기본 스타일 / 선택 완료: 완료 스타일 / 현재 문제: 강조 스타일

#### 제출
- "제출" 버튼은 20문제 모두 선택 완료 시에만 활성화
- 제출 버튼 위에 미선택 문제 수 표시 (예: `3문제 미선택`)
- 제출 클릭 시 즉시 채점 후 `/result/[sessionId]`로 이동

### 3. 결과 화면 (`/result/[sessionId]`)

#### 요약
- 총점: `N / 20`
- 정답 수, 오답 수, 점수에 따른 평가 메시지

#### 카테고리 분석
- 카테고리별 정답률 가로 프로그레스 바 (80%↑ emerald, 60%↑ yellow, 미만 red)

#### 문제 리뷰 탭
- **오답 탭** (기본): 틀린 문제 한 번에 하나씩, 이전/다음 네비게이션
  - 각 오답: 번호·카테고리, 문제 텍스트, 보기(오답→빨간색, 정답→초록색), 해설, 신고 버튼
- **전체 탭**: 20문제 전체를 아코디언 목록으로 표시. 정답/오답 배지로 구분. 펼치면 ResultCard 표시

#### OG 메타태그
- `page.tsx` 서버 컴포넌트에서 `generateMetadata` → 점수·카테고리 기반 동적 OG 태그
- 클라이언트 코드는 `ResultClient.tsx`로 분리

#### 북마크
- ResultCard마다 북마크 버튼
- 로그인 시 토글 가능. 북마크된 문제는 마이페이지 "북마크한 문제" 탭에서 확인
- 페이지 진입 시 `/api/mypage/liked-questions`로 북마크 상태 일괄 조회해 초기 세팅

#### 공유
- 공유 모달: ① 카카오톡 (Kakao SDK `sendDefault`) ② 다른 앱 (Web Share API) ③ 링크 복사

## 에러 케이스 및 엣지 케이스

### E-1. 페이지 새로고침 (퀴즈 진행 중)
- **동작**: localStorage(`quiz-progress-{category}-{firstQuestionId}`)에 저장된 진행 상태 자동 복원
- questionIds가 불일치하면 무시하고 새로 시작. 제출 완료 시 삭제.

### E-2. 문제 풀(pool)이 20개 미만
- `sample.ts`에서 guard 처리 — pool 전체 반환 + 콘솔 에러

### E-3. 브라우저 뒤로가기 (`/result` → `/quiz/play`)
- `/quiz/play` 재진입 시 새로운 퀴즈 세션으로 초기화됨

### E-4. 비로그인 접근 (로그인 필요 페이지)
- `/api/auth/signin?callbackUrl={currentUrl}`으로 리다이렉트

### E-5. 닉네임 미설정 접근
- `/auth/setup-nickname?callbackUrl={currentUrl}`으로 리다이렉트

### E-6. 관리자 전용 페이지 (일반 유저 접근)
- `/`로 리다이렉트

### E-7. 카테고리 문제 부족 (10개 미만) 퀴즈 시작
- UI 버튼 비활성화. API 레벨에서도 400 반환.

## 퀴즈 선택 화면 (`/quiz`)

- **ALL**: official + approved 문제 전체에서 랜덤 20개
- **카테고리별**: 선택한 카테고리에서 랜덤 20개
  - 문제 수 표시: "자료구조 (42문제)"
  - 10개 미만 시 비활성화 + "최소 10개 필요"
  - 로그인 사용자: 내 카테고리 정답률 표시
- **오답 복습**: 복습 예정 문제만 모아 review 모드로 시작 (랭킹·뱃지·연속출석 제외)
- **북마크 복습**: 북마크한 문제만 review 모드로 시작

## 게시판 (`/board`, `/board/[id]`, `/board/submit`)

#### 목록 (`/board`)
- 키워드 검색 (URL `?q=`, 서버사이드 ILIKE)
- 카테고리 필터, 상태 필터, 정렬 (등록일/정답률/좋아요)
- 20개/페이지, 서버사이드 페이지네이션
- `BLINDED` 문제: 일반 사용자에게 숨김

#### 상세 (`/board/[id]`)
- 문제 전체 (보기 4개, 정답, 해설)
- 통계: 시도 횟수, 정답률
- 북마크 버튼 / 신고 버튼 (로그인 + 본인 제외)
- 댓글

#### 문제 등록 (`/board/submit`)
- 필드: 카테고리, 문제, 보기 A~D (AI 자동 생성 버튼), 정답 선택, 해설
- 제출 → `status: PENDING`. 거절된 문제 재요청: `?resubmit={id}` 파라미터로 기존 내용 불러오기

## 관리자 패널 (`/admin`)

`role: ADMIN` 전용. 미들웨어에서 일반 사용자 차단.

**탭 구성**:
| 탭 | 내용 |
|----|------|
| 승인 대기 | PENDING 문제 목록, 승인/거절, 유사 문제 패널 (pgvector), 일괄처리(bulk) |
| 신고 접수 | PENDING 신고 목록, 블라인드/무시, 일괄처리 |
| 문의 | 전체 문의 목록, 답변 작성, 상태 변경, 일괄처리 |
| 유저 관리 | 유저 목록 서버사이드 검색·페이지네이션, 권한 변경/삭제, 일괄처리 |
| 통계 | 일별 방문자·세션·문제 제출 차트, 카테고리별 분포 |
| 활동 로그 | 관리자·사용자 행동 전체 기록, 액션/유저 필터, 슬라이드 패널 상세 |
| 오류 내역 | ErrorLog 목록 |
| 포인트 내역 | PointTransaction 목록 |
| 금칙어 관리 | 커스텀 금칙어 목록, bulk 등록/삭제 |

**AI 문제생성**: 관리자가 카테고리·수량 지정 → GPT-4o BATCH_SIZE=10으로 순차 생성, pgvector 중복 검사 후 PENDING으로 저장

## 마이페이지 (`/mypage`, `/mypage/[category]`)

- **요약 카드**: 총 퀴즈 횟수, 전체 정답률, 연속출석 N일, 출석 달력 (실제 월 달력, 날짜 숫자 표시)

## 소셜 기능

### 친구 (`/friends`)
- 친구 추가/삭제, PENDING/ACCEPTED 상태
- 친구 패널 (우측 슬라이드): 온라인 상태 실시간 반영, 대결 초대, 채팅

### 1:1 채팅 (`ChatWindow`)
- 친구 패널에서 채팅 버튼 클릭 → 채팅 창 슬라이드
- Supabase Broadcast 실시간 수신
- 미읽 메시지 수: 채팅 버튼에 배지 오버레이 (orange = 미읽 있음, sky = 온라인만)
- 로그아웃 시 채팅 기록 삭제

### 온라인 상태
- Supabase Presence 기반 (`useSupabaseRealtime`)
- 15초 간격 heartbeat (`/api/presence/heartbeat`)

### 공개 프로필 (`/u/[nickname]`)
- 닉네임, 연속출석, 포인트, 뱃지, 최근 세션 기록
- 공개 설정(PUBLIC/FRIENDS_ONLY/PRIVATE)에 따라 접근 제어
- 프로필 변경 시 Broadcast로 실시간 반영 (새로고침 불필요)

## 1:1 대결 (`/battle/[id]`)

- 친구에게 대결 초대 → 수락/거절 알림
- 카테고리 선택 후 각 20문제 동시 진행
- Supabase Broadcast(`csora-battle-{roomId}`)로 양쪽 클라이언트 실시간 동기화
- 폴링 fallback: 일반 1s, 5초 단축 모드 500ms
- **문제 제한 시간**: 20초/문제
- **연속 쌍방 스킵 규칙**:
  - 1회: 5초 단축 타이머 적용
  - 3회: 무효(void) 처리
- **quitRequestBy**: 한 쪽 중단 요청 → 상대방 확인 후 종료
- 대결 결과: 승/무/패, 누적 전적 집계

## 업적/뱃지 시스템

- BadgeType: 24종 (퀴즈 횟수, 정답률, 연속출석, 대결 승수 등)

- review 모드 세션은 뱃지/레벨업 카운트 제외
